<div class="info-box" style="margin-top: 2.5rem;"> <h3>Announcing Flux 2.10 GA</h3>
<p> We're happy to announce the <strong>Flux 2.10 General Availability</strong> release, bringing SPIFFE workload identity to the GitOps Toolkit. </p>
<p> Key highlights include: </p>
<ul>
  <li>SPIFFE integration (RFC-0014) - Flux objects can present short-lived credentials to registries, secret stores, and remote clusters</li>
  <li>Inter-controller mutual TLS</li>
  <li>Object-level workload identity is now generally available</li>
  <li>Multi-tenant artifact generation</li>
  <li>Alerting APIs (<code>Alert</code>, <code>Provider</code>, <code>Event</code>) promoted to stable v1</li>
  <li>New alerting providers: Zoom Team Chat, incident.io, and Mastodon</li>
</ul>
<p> Ecosystem News: </p>
<ul>
  <li>Flux Operator Web UI gains metrics and Node debugging views</li>
  <li>Flux MCP Server adds resource tracing, manifest diffing, and cluster event tools</li>
</ul>
<p> <a href="https://fluxcd.io/blog/2026/10/flux-v2.10.0/" target="_blank" rel="noopener"> Read the full 2.10 Release Announcement </a> </p> </div>
